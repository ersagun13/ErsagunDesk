# Open-source attribution

ErsagunDesk is based on [alztrk/OpenWidget](https://github.com/alztrk/OpenWidget), a Windows desktop HUD published under the MIT License.

The original contributors' copyright and permission notice are preserved in [LICENSE](LICENSE).
ErsagunDesk maintains the functional module set while using distinct branding, an Ersagun graphite/turquoise theme, Ankara-first defaults, new local application storage paths, and hardware defaults without any original author's sample devices or prices.

OpenWidget's developers do not sponsor or endorse this project.
